# Batch 2 设计依据：从“算法变换”转向“缺失信息补全”

## 1. Batch 1 真正证明了什么

Batch 1 的 16 个候选均通过了格式、gene order、hash 与提交链路检查，因此低分不能主要归因于工程封装。当前 best 仍是 T1 48.5、T2 55.7、T3 45.3；其中 T3 两个 signed-response lane 都低于 `wt_identity`，T1 的 mass/residual lane 只比旧 baseline 略好但未超过 current best。

最关键的失败假设是：

- T3 把 WT 相关性当成 KO 因果方向，并借用另一个 KO 的幅度；
- T1 在只有两个训练阶段的条件下，试图靠状态质量公式推断晚期状态；
- T2 通用后配对没有与 server NFS 对齐的可验证目标。

## 2. 第一性原理诊断

一个预测问题能否通过增加模型容量改善，取决于训练信息是否识别了目标。

### T1

官方只给 E8.5 和 E9.5。它们可以告诉模型“已有状态如何变化”，但不能充分告诉模型：

- E10.5/E12.5 会出现哪些新状态；
- 哪些基因程序会在晚期打开；
- 早期状态向多个后继状态分支的方向。

因此 T1 首先需要 **允许的稠密早期时间序列 + 允许的晚期状态/程序锚点**，之后 OT、flow 或 decoder 才有信息可学。

### T3

一个 Mab21l2 KO 只能提供“扰动响应通常长什么样”的弱统计模板，不能识别 Gata4 或 β-catenin 的具体下游符号。T3 首先需要：

- 目标基因的直接结合或调控证据；
- 目标阶段和谱系中的 context-specific GRN；
- 条件基因型信息：Mesp1-Cre、Gata4 F/F、Gata6 F/+；
- 不确定时向 WT 收缩的规则。

### T2

外部空间数据只在它提供可迁移的目标形态/生态位信息时有价值。T1 没有空间分，T3 当前也不以形态排名；为它们预训练空间模型不会补足主要识别缺口。T2 的相关空间阶段又受保护窗口约束，因此本批仅保留条件路线。

## 3. Batch 2 原子与评分原子映射

| Atom | 新引入的信息 | 主要评分原子 | 不试图解决 |
|---|---|---|---|
| B2-T3-A1 | GATA4/GATA6 直接性、方向、谱系 gate | E1、E2、K1、K2，间接保护 MMD/CSS | 精确 PSS、形态 |
| B2-T1-A1 | 跨图谱状态词表、晚期允许程序 | P1、P2、P3、P4，部分 E1/E2 | 完整连续动力学 |
| B2-T1-A2 | 6 小时时间转移 operator | E1、E2、P2–P4 | 从无到有识别新状态 |
| B2-T3-A2 | 通用扰动稀疏度、幅度、异质性 | E3、P3、P4，保护 K2 | 目标基因方向 |
| B2-T1-C1 | 状态支持 × 动力学 | T1 全部表达/群体原子 | 新数据、新拟合 |
| B2-T2-X1 | 允许的空间形态先验 | G2、G3 | 未验证的 NFS 配对 |

## 4. 为什么这些仍被称为“原子”

每个 atom 都有一个不可替代的信息输入和一个明确可提交终点：

- T3-A1 的不可替代信息是 target-specific signed prior；
- T1-A1 的不可替代信息是 target-stage 之前/之后允许的 state support；
- T1-A2 的不可替代信息是稠密 early-time operator；
- T3-A2 的不可替代信息是 perturbation response shape，而不是方向；
- C1 只检验两类信息是否可兼容，不重新拟合。

把它们继续拆开会产生没有提交意义的中间文件；把它们合并成端到端模型又无法知道是哪类信息有效。

## 5. 优先级

1. **T3-A1**：失败归因最明确，数据量小，能快速结束为提交候选。
2. **T1-A1**：直接补 T1 最不可识别的状态支持。
3. **T1-A2**：在 A1 的统一词表上训练时间 operator，复用价值高。
4. **T3-A2**：只有当 A1 的方向至少不劣于 identity 时才值得校准幅度。
5. **T1-C1**：A1/A2 至少一个有正信号后再机械组合。
6. **T2-X1**：规则和收益都不够清楚，暂不消耗。

## 6. 本批的成功定义

不是“外部数据模型一定超过当前 best”，而是：

- 数据来源与删除过程可审计；
- 每条路线补的是原训练集缺失的信息，而非只增加容量；
- 每个 atom 都形成真实可提交候选；
- 失败时能区分是 state support、temporal operator、signed prior 还是 response magnitude 失败；
- 不以泄漏风险换取排行榜分数。
