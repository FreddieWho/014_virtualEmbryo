# T2 source admission and distribution

The JSON permits are project source-use reviews, not organizer clearance or legal licences. Source terms and attribution remain controlling.

- E14.5 MOSTA: Chen et al., Cell 2022, DOI 10.1016/j.cell.2022.04.003; STOmicsDB accession STDS0000058. Public source file URL and exact original SHA256 are in PUBLIC_INPUTS.json. Policy: https://db.cngb.org/stomics/policy . Public-access/research and attribution provisions are recorded; no CC licence is invented. The 2.16 GB source and derived H5AD are not redistributed here. Stage is assigned from the official stage-separated file, not inferred from expression. `endpoint/T2_DATA_PERMIT.json` records fields, filters, exclusions and limitations. `gene_presence.tsv` and `selected_rows.tsv` preserve exact selections.
- GO/InterPro sequence-only function topology: source OBO release 2026-07-26 and mouse GAF generated 2026-07-28; GO CC BY 4.0, https://geneontology.org/docs/go-citation-policy/ . Exact source hashes and filters are in go_topology/T2_DATA_PERMIT.json. Retain attribution on reuse. Only InterPro IEA sequence-signature assertions, exact panel/mouse taxon, no NOT/context extension, and is_a/part_of propagation are used. Derived JSON/evidence/module lists are included so historical controls need not depend on mutable `current.geneontology.org` URLs. Those current URLs do not guarantee historical byte availability; source hashes must match for any raw-source rebuild.
- External MOSTA E9.5: intake review retained solely as considered-not-used provenance. Its model_input_allowed intake field is not a statement that the selected model used it. No external E9.5 binary is included or needed.
- Official inputs: fetch released T2 E8.25_late/E8.75/E9.5 from https://virtualembryo.ai/challenge/data#download using official controls. Authentication/eligibility may be required. No signed URLs, personal account fields or private storage links are published. Exact original local hashes are recorded, not represented as organizer-published checksums.

The broader original intake work notes and delivery receipts were omitted; the curated permits, identities and result report contain the relevant scientific provenance. Historical absolute workspace paths in frozen evidence identify original locations only. Use the new portable entrypoints for execution.
