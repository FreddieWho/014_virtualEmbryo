## 1. 机制（冻结，跑后不得回改）

现役 v0010 的 L2 臂是 **mean + mass bridge**：按细胞类型把源阶段的表达取值搬到目标位置，再做组成重采样。本路线只改**取值从哪个源细胞借**，不改几何、不改 panel、不改行/列顺序。

1. **正反两次 CPD 求对应**：对源阶段（E7.25）与目标几何各做一次条件概率密度（CPD）对应估计，得到两个方向的软对应矩阵 `T_fwd`（源→目标）与 `T_bwd`（目标→源）。
2. **一致性置信度**：对每个目标细胞 `i`，令
   `conf_i = mean_j [ T_fwd[j,i] · T_bwd[i,j] ]`（正反往返一致性），落在 [0,1]。
   **该式的归一化在跑前定死**：按每基因表达量对 `T_fwd·T_bwd` 做行归一后再取均值，避免高表达基因主导。
3. **层内借表达**：把目标点云按几何（扩散嵌入 / 密度分带）划分为 `L` 个解剖层（跑前定 `L=6`）。目标细胞 `i` 只向**位移后落入同一层内**的源细胞借表达；层内候选为空时退回该层的全局均值。
4. **水平/对比度解耦**：每基因拆成**全局水平**（阶段间均值插值，位置无关）与**局部对比度**（基因在该细胞上相对本层均值的偏离）。现役桥把两者混在一个取值里，本路线显式分开：水平走独立通道，对比度走层内借用通道。**层内对比度项在使用前按该层内标准差归一**，以免层间尺度差异污染。
5. **置信度加权混合**：最终取值 = `w_i · (层内借用取值) + (1 − w_i) · (全局均值插值)`，其中 `w_i = f(conf_i)`，`f` 跑前定死为**线性** `w_i = clip(conf_i, 0, 1)`。**不引入需要调的超参**（这是相对 `E-N1 SBL` 的关键设计约束，见 §6）。

**与已关闭 5 轴的距离**（M0 §7）：不做行-点最优传输的软 plan 求解（CPD 是对应估计，不是 OT）；不用 FGW 目标；不做邻域平滑预测场；不调位移量；不做条件流匹配/VAE+SDE/扩散/moscot/动力学。

## 4. 判定（本板的关键限制，必须随附）

**按 `D-20260927-T2M0APPXB-001`（M0 附录 B），`T2:embryo:val_interp` 的 5% 三分类已停用。** 因此：

1. 本路线**不以本地 5% 规则作否决依据**；本地读数**只作记录**。
2. **决策权在服务器**。因此本路线的正确执行方式是：**跑完 → 如实报告全部读数 → 由用户决定是否消耗一次提交配额**。
3. 与 `E-N1 SBL` 的区别（本路线相对有利的一点）：SBL 的失败幅度是 10–13 倍，**远超任何噪声带**；本路线若本地读数与父版本**同量级**（差 < 5%），则属于「无法从本地分辨」，**不构成负面证据**，不得据此关闭路线。
4. **embryo 板存在本地完全看不见的 3.4 分坐标尺度杠杆**（`D-20260927-T2VALIDATE-001`）。本路线不改坐标，因此**它原则上不能捕获该杠杆**——这是接受本路线时的已知上限，**不是**可以通过调参解决的问题。

## 5. 预声明失败签名（跑前定死）

| 签名 | 含义 | 正确反应 |
|---|---|---|
| L1 ≡ L2 逐位相同 | 「层内」约束无作用 | **按预声明关闭本路线**，不得改 `L` 后重跑 |
| `conf` 分布极度集中（多数细胞 `w` 几乎相同） | 正反一致性不具区分力 | 记录；**不调** `f` 的形式（跑前已定为线性） |
| 层内候选为空比例过高 | 分层太细或几何不可分 | 记录；**不加大** `L` 后重跑 |
| `de_score` 掉而 `nmmd` 不涨 | 全局水平通道被破坏 | 拆开两条通道定位，**不**混合权重后重跑 |
| 与父版本 v0010 的 nmmd 差 > 20% | 机制改动幅度过大 | **视为实现缺陷**，核对坐标/行序后再判，**不**当作机制结论 |

**否定判据**：若 L1 与 L2 的 `neighborhood_mmd` **均差于 do-nothing 基线**（0.031240）**超过 5%**，本路线立即关闭，理由是「改动幅度失控」；若二者与父版本同量级（|Δ| < 5%），**不关闭**，交服务器仲裁。

## 6. 与 `E-N1 SBL` 失败的关系（设计动机，非事后辩护）

`E-N1 SBL` 的失败根因是**全局水平与场项之间没有幅度控制**（`D-20260927-T2EN1-002`）：z-score 回归产生的场项带标准差量级动态范围，把总质量抬高 53%+。

本路线在设计层面**直接封堵**该失效模式：局部对比度项**在层内按标准差归一后再用**（§1.4），而全局水平走独立通道（§1.5）。这是本路线相对 SBL 的结构性优势——**但它不构成对本路线成功的预期**，只是移除了一个已知的失败原因。
