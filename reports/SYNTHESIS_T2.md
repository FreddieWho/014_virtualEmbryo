## 外推这条线上什么有效

v0030 相对基线 50.53 是 +0.59，也超过旧 board-best v0011 的 50.64。收益在 de / variogram / nmmd；d2、occ、scale 钉着没动。library 守恒解开了 DE，覆盖更多细胞类型的 crosswalk（v0031 = 49.91）反而把 mmd 打塌。de 和 mmd 在这张榜上是反向杠杆，单优化一边会跷跷板。

剂量 0.5 / 自适应 / 0.9 在服务器上单调，0.9 最好。同族再调 C、剂量、分类型权重，三点都在 51.02–51.14，互相平局。

## 已经关掉的

- 空间平滑：本地能赢，服务器全输。代理在这一族上是反的。
- FGW ε 和“把同一目标解得更低”：落点换了，榜不动。`reports/T2_LEADS_CLOSURE_20260927.md`。
- 谱系映射 delta、三阶段趋势外推、QTE / Route C：服务器全 REJECT。本地八通道综合分和服务器的相关在扩样后掉到约 0.12，不能再拿它决定提交。variogram 通道本身在那一轮是榜上最好的，这不等于综合分可用。
- 把坐标缩到 0.9（v0029 = 49.40）：本地尺度项变好，服务器尺度技能变差，其他项不动。`t2_scale_score_review_20261003`。
- 低幅度空间探针：心脏插值 61.52，低于当时现役，没有“本地差、服务器反转”。

## 本地分怎么用

外推代理曾在收缩族上和服务器方向相反，在空间族上把服务器会输的当成赢。Route C 之后，禁止用本地综合分单独证明该提交。同族之内，留阶段 dev 有时能排序（HOLDOUT10 剂量），跨族不行。dev 把位移幅度奖得比服务器慷慨：v0030 的 dev 没到 0.90，服务器仍然晋级。两个目标不要互相抵销。reserve 仍是 `NOT_RUN`。
