## 3. 复盘发现：共同 decoder 改变了模型本来预测的响应

上轮 decoder 的约束是保留状态内 `mean(expm1(X))`，即 count/intensity 均值；而锁定 scorer 的 pseudobulk 是 `mean(X)`，即提交的 **log 表达均值**。两者不等价。把同一总强度摊到更多细胞，count 均值可以不变，log 均值与基因间关系却会变。

一个简单例子：两个细胞原来是 `[0,10]`，改成 `[5,5]`，count 均值都是 5；但 `log1p` 均值从约 1.20 变成 1.79。没有增加总量，评分看到的群体表达却升了。这就是为什么“均值保留”在这里不能只检查 count 空间。

本次对全部 7,449×500 原始模型输出和最终上传矩阵逐项检查，未使用 KO 真值：

| 路线 | decoder 前最大下游群体 log-mean 位移 | decoder 后 | 原始/最终变化向量 cosine | 变化方向翻转数 |
|---|---:|---:|---:|---:|
| CellOracle | 0.0196 | 0.0504 | 0.979 | 0 / 26 |
| 独立活动 | 0.2896 | 0.7474 | 0.479 | 64 / 316 |
| 功能线性 | 1.6117 | 3.0478 | 0.777 | 0 / 317 |
| 功能双线性 | 1.6105 | 3.1951 | 0.773 | 0 / 321 |
| Scouter | 0.7547 | 2.7781 | 0.819 | 1 / 440 |
| GEARS | 1.2562 | 2.8820 | 0.907 | 0 / 314 |

翻转的分母只包含转换前后变化绝对值都 >0.001 的下游基因；不把微小舍入扰动计为方向翻转。这里的方向是模型相对 WT 载体的原预测方向，**不是相对未知真实 KO 的正确/错误方向**。

count 均值约束确实满足，最大状态内相对差异约 2.1×10⁻⁶；但活动路线变化向量的 cosine 仅 0.479，说明“保住 count 均值”远不足以保住评分使用的响应。这是实现设计和上轮验收的明确遗漏：验收检查了宣称的 count 约束，却没有检查评分空间的响应是否被改变。

因此，共同 decoder 是有独立效应的模型组件，不能被当作透明格式转换。上轮来源侧检测率条件拟合变好，也不能当作整个预测链已经验证：那一诊断给定的是来源实际强度变化，不是对未知扰动预测后的端到端验证。

**限制：** 未转换的原模型输出没有单独服务器评分；不能据本次局部比较证明“去掉 decoder 就会涨分”，也不能把全部掉分唯一归因于它。见 [OUTPUT_AUDIT.json](OUTPUT_AUDIT.json)、[实现](../../scripts/t3_priority_six/calibrate.py:20) 与 [锁定 pseudobulk](../../third_party/veckit/common/core_metrics.py:71)。

## 4. 更早一层的问题：低信息来源经比例映射被放大

功能模型的目标转换使用来源预测/对照的强度比例。对照近零时，`0.001` pseudocount 决定了大部分分母；一个很小的预测绝对增量，就可能变成很大的倍数，再乘到目标胚胎本来表达很强的基因上。

具体例子 **Stmn2**：

1. 来源的 220 个 control 细胞全部为零。
2. 最终功能线性模型预测来源 log 表达增量只有 **0.02842**。
3. 加入 `0.001` 分母后，它被解释为约 **29.83 倍**强度。
4. 在目标中，该基因原有 WT 平均强度约 8.97；原始输出的群体 log-mean 位移约 +0.298，再经检测率 decoder 变成约 **+3.048**。

该大预测来自**低信息来源 + 比例分母 + 跨域转换**，缺少支持这一目标效应的强证据。来源对照没测到不代表生物学上永远不表达；但它也不足以可靠估计目标域的 fold change。

功能线性、双线性和 GEARS 最大的 20 个目标群体位移，**20/20** 都来自来源 control 平均强度 <0.1 的基因。这是可复现的风险集中现象，不是隐藏真值推断。不能把 0.1 临时当成官方阈值，或为了挽救本次模型事后删除这些基因。

Scouter 还有额外接口问题：目标反事实对比使用 zero embedding 的 control 输出，而作者 BalancedDataset 没有直接监督这个 reference；它的差分尺度本身就未被完整来源验证。其 GO128 表示也不是论文 GenePT1536。GEARS 的作者原版被完整运行，但本轮成人成纤维细胞→胚胎的上下文迁移不是作者原验证场景。

这些发现约束的是**这次具体来源、表示、reference 与 decoder 的组合**，不是对神经网络或原论文方法的普遍证伪。详细来源复算见 [TRANSFER_AUDIT.json](TRANSFER_AUDIT.json)。

## 5. 对六条路线分别怎么处理

**CellOracle：保留为响应先验，不再据旧适配器的工程缺陷推定高分空间。** 新版与旧版服务器平局已经回答了这轮的核心问题。后续若继续，须引入可验证的新方向/上下文信息，或明确验证映射层；单纯扩大幅度、提高改变基因数和换状态聚合没有本批正证据。

**状态质量：当前硬转移实例保持 NULL。** 上轮全量 native 计算没有跨状态事件，所以这条没有候选，也没有服务器回分。不能把本批六件分数写成质量路线已经评过分。连续/soft mass 或生存模型属于新分支，应保留当前零效应结果。

**独立活动：概念仍是线索，但此实现不晋级。** WT 重构的小幅改进不验证功能失活；状态内第 1 百分位也不是已知的 Gata4 功能归零。共同 decoder 又改变了 64 个非微小响应方向。应先解决活动 reference 与完整评分空间转换，不能把 direction 略高当因果机制证据。

**功能线性/双线性：保留作强基线，否定当前组合的提分主张。** 来源 test 小幅胜过平均响应是真的；目标服务器退步也是真的，二者不矛盾。两个成人 sample 的 control 上下文并没有覆盖胚胎的细胞状态与阶段。ratio adapter 的薄弱支持已经定位，但没有单独服务器消融，不声称它是全部掉分的唯一原因。

**Scouter/GEARS：当前配置关闭，原方法与更大合法来源仍是 leads。** 它们在来源侧已没有胜过平均扰动，目标侧继续退步。再次尝试必须说明改变的是数据、表示、reference 还是上下文接口，不能继续把“使用了神经网络/图”当作有效性证据。
