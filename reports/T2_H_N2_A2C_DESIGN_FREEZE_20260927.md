## 1. 现役机制与本路线的差异（先说清「改什么」）

现役 v0013 的 L2 臂 = **pycpd 几何 + 秩-0 均值桥 + 组成重采样**。其中「秩-0 均值桥」意味着：目标细胞 `x` 的预测表达 = 目标阶段的**每基因全局均值**（一个常数向量），与 `x` 的位置**无关**。这是该臂最大的简化。

本路线把这个常数向量换成**位置函数**：

`X̂(x) = m_g(阶段间插值) + f_g(a(x))`

其中 `a(x) ∈ R^d` 是目标细胞 `x` 的**低维解剖坐标**，`f_g` 是逐基因的解剖位置函数。

## 2. 机制（冻结，跑后不得回改）

1. **解剖坐标的构造**（全部来自纯几何 + 细胞类型，**不使用目标表达真值**）：
   - `a_1(x)`：**房室交→心尖弧长**。用目标点云（pycpd 结果）构造中心线，取每个细胞到中心线的弧长参数，归一化到 [0,1]。
   - `a_2(x)`：**壁层深度**。用局部邻域内细胞到点云边界的距离代理，按每细胞归一化。
   - `a_3(x)`：**局部密度**（k=20 邻域半径的负对数），归一化。
   - 这 3 维构成 `a(x) ∈ R^3`。
2. **沿用现役 pycpd 流场**：源细胞的坐标经**同一套** pycpd 流场搬到目标端，得到每个源细胞的 `a_src`。**pycpd 参数与实现逐字节不动**（父版本已冻结）。
3. **B 样条基**：对 `a(x)` 三个分量各构造固定 `q=5` 次 B 样条基（每维 6 个基函数，含截距共 17 个设计列）。`q` 跑前定死。
4. **跨两阶段共享的逐基因逐细胞型拟合**：对每个**括号源阶段** `s ∈ {E8.25_late, E8.75}`（**经 BOARD_REGISTRY 与 `t2_s3_shape_field.py` 双向核对确认，见 §7.1**），在 `(a_src(s), celltype(s))` 上用 ridge 拟合 `f_g^{s}(·)`，**两阶段共享同一组样条系数**（跨阶段共享是本路线的核心约束——它保证阶段间只移动解剖坐标而不重新学一套图案）。
5. **阶段轴中点取值**：目标为 **E8.5**，在 bracket `[E8.25, E8.75]` 上的位置为
   `λ = (8.5 − 8.25) / (8.75 − 8.25) = 0.5`，
   即**两侧等权平均**。实现时必须用 `λ` 而非硬编码 0.5，并断言 `|λ − 0.5| < 1e-12`。
   **禁止把 E8.5（目标 stage 本身）用作源阶段——那是 target 泄漏。**
6. **组成重采样逐字节不动**：父版本 v0013 的 L2 组成重采样步骤原样保留。

**与已关闭 5 轴的距离**（M0 §7）：pycpd 几何与组成重采样均不动；**不做行-点最优传输 / FGW 目标**；不做邻域平滑预测场；不调位移量；不做条件流匹配/VAE+SDE/扩散/moscot/动力学；不把 `variogram`（基因间协方差）当被预测量。

## 5. 判定

**本板 `neighborhood_mmd` 与服务器同向**（Spearman −0.559，`D-20260927-T2VALIDATE-001`），但 **5% 规则在本板仍然有效**（M0 附录 B 明确维持 heart_interp / heart_extrap）。

因此本板采用**三档**判定（比 embryo 板严格，因为本板本地指标确有预测力）：

| 本地 `neighborhood_mmd` 相对 do-nothing（0.112028） | 判定 | 动作 |
|---|---|---|
| 改善 > 5%（更低） | `LOCAL_PROMOTE` | 生成候选，建议消耗提交配额，由服务器仲裁 |
| 劣化 < 5% | `TIER` | 不建议提交；**不关闭路线**（记录，如实上报） |
| 劣化 > 5% | `LOCAL_REJECT` | **不关闭路线**——本板 `d2_shape` 与服务器反向（+0.629），几何形状分不得单独作否决（`D-20260927-T2M0APPXB-001` §B.3）；只有当 `neighborhood_mmd`、`mmd_u`、`energy_distance` **三者同向劣化**时才升级为 `REJECT` 并关闭 |

**分布侧会签**：`mmd_u` 在本板跨族有效但**族内成对比较反向**（`D-20260927-T2PROBED-001`）。故 L1 vs L2 的成对比较**不得单独依赖 `mmd_u`**；须与 `neighborhood_mmd` 同向才作数。`mmd_u` 另有 9.0% 种子噪声，本就不支持 5% 量级判据。

## 6. 预声明失败签名（跑前定死）

| 签名 | 含义 | 正确反应 |
|---|---|---|
| L1 ≡ L2 逐位相同 | 跨阶段共享无约束力（数据不足以分辨） | 记录；**不**改 `q` 或改成分组后重跑 |
| `f_g` 学出的解剖依赖**远小于**现役组成重采样带来的变化 | 秩-0 均值项本就不是瓶颈 | 记录为**定位性结论**（本路线证伪「均值项是瓶颈」），**不调**样条阶数 |
| 层间尺度比异常（某些 `f_g` 幅度远大于层间差异） | 与 `E-N1 SBL` 同型的幅度失配 | **判实现/设计缺陷**，核对 `f_g` 是否按层内标准差归一；**不**靠缩放系数补救 |
| `occupancy_dice` 掉而 `nmmd` 不涨 | 组成重采样被动到 | 逐字节复核组成重采样是否被改动；**不**改组成比例后重跑 |
| 坐标 SHA 与父版本不符 | 几何被动 | **实现缺陷**，修正后重跑；**不**记为「轻微差异」 |

**否定判据**：L1 与 L2 的 `neighborhood_mmd` **同时**较 do-nothing 劣化 > 5%，**且** `mmd_u` 与 `energy_distance` 同向劣化 → 关闭本路线，理由记为「解剖位置函数替换均值项无效」。

## 8. 已知上限（接受本路线时的诚实前提）

`D-20260927-T2VALIDATE-001` 发现 heart_interp 板的板最佳 v0013（62.04）其 `d2_shape` 是 12 条候选中**最差**的——即**服务器奖励了形状更差、组成更好的候选**。本路线不改善形状（几何不动），因此其收益**只能来自均值项的定位精度**；若现役的秩-0 均值项本就不是瓶颈（见 §6 第二行签名），本路线会给出**定位性否定**而非分数。这是有价值的负结果，但不应被当作「提分机会」来预期。
