## 1. 官方指标分层的判决性证据（此前从未被核实）

`third_party/veckit/T2/metrics_v2.py` 模块 docstring 原文：

```
PRIMARY — expression: de_score, de_direction, energy_distance, mmd_u, variogram
PRIMARY — shape:      d2_shape, sliced_wasserstein, occupancy_dice
PRIMARY — growth:     scale_log_ratio, count_log_ratio
PRIMARY — local:      neighborhood_mmd
CONSTRAINT:           pb_rel_err, variance_ratio, composition_JSD, pseudobulk_pearson, morans_I_agreement
```

三条结论：

1. **`morans_I_agreement` 是 CONSTRAINT，不是分数。** 此前把 heart 候选的"两个耦合指标"并列作为判据时，它只是辅助证据，不参与 leaderboard 聚合。
2. **`variogram` 是 PRIMARY-expression，实现为 `variogram_score(pred_X, true_X)`，不接收坐标。**
3. **`d2_shape` / `occupancy_dice` / `sliced_wasserstein` / `scale_log_ratio` 是纯坐标指标，完全不看表达。** 而现役流水线的几何是从 pycpd **逐位继承、冻结**的 —— 因此这四个子分对任何只改表达的候选**恒定不变**。

registry 实际登记的 T2 六个子分（以 heart_interp v0009 为例）：`de_score 57.8 / de_direction 60.2 / mmd_u 53.9 / variogram 32.2 / d2_shape 62.0 / occupancy_dice`。**`variogram` 32.2 是唯一离群项，比其他低 20 分以上。**

## 2. 闸门 A：官方 `variogram` 到底奖励什么

### 判据逻辑的自我纠正

脚本原本的判定是「A1 行置乱后相对变化 < 1e-9 ⇒ 坐标无关」且「A2 基因置乱 > 1.5× ⇒ 由基因联合驱动」。两处都错：

- `variogram_score` 内部会 `rng.choice` 抽 `n_cells=1500`，本身带蒙特卡洛噪声，用 `1e-9` 位级阈值要求它**必然失败**；
- A2 我把基因在**两侧同时**置换——按对称性这本就不该变差，拿它当判据方向就是反的。真正该用的是 A2b（仅预测侧置换），我算出来了却没写进判据。

### 实测（6 个 seed）

| 对照臂 | 相对极差 | 相对 base 倍数 |
|---|---:|---:|
| base（未置乱） | 4.19% | — |
| **A1 行置乱（坐标不动）** | 4.17% | 均值偏移 **−0.81%**，**落在同输入种子极差内** |
| **A2b 仅预测侧基因置乱** | 3.57% | **4.35×** |
| A2 两侧同置乱 | 4.69% | 0.997×（对称不变，符合预期） |
| 真值对自身 | — | 0.000591 |

**结论（判为 CONFIRMED）**：行置换在统计上不可分辨 ⇒ 该分数**坐标无关**；基因联合被独立打乱则恶化 **4.35 倍** ⇒ 它度量的确是**基因间联合结构**，且以真值侧与预测侧的**基因配对对齐**为参照。

> **教训（写下来防止重犯）**：三份 researcher 简报**各自独立**收敛到"空间变异图 / 空间变异函数"，而官方叫 `variogram` 的是**基因间协方差**。**名字撞了，被预测量完全不同。** researcher 无代码读权限，无法看到 `metrics_v2.py` 的分层声明，因此这不是它的失误；但任何后续检索/实现都不得再以"官方 variogram ⇒ 空间变异函数"为推理前提。

## 5. 指标噪声标定（对 M0 冻结规则的校准）

heart_interp v0013，同一输入跑 4 个 seed（经真实 `score_h5ad` CLI）：

| 指标 | 相对极差 | 含义 |
|---|---:|---|
| `neighborhood_mmd` | **0.00%** | **完全确定** |
| `de_score` / `de_direction` / `morans_I_agreement` | 0.00% | 完全确定 |
| `occupancy_dice` | 3.01% | 有噪声 |
| `variogram` | **4.18%** | 有噪声 |
| `d2_shape` | 4.50% | 有噪声 |
| `energy_distance` | 6.96% | 噪声大 |
| `mmd_u` | **9.00%** | 噪声最大 |

两条后果：

1. **M0 冻结的「5% 判据定在 `neighborhood_mmd`」被硬事实确认为正确选择**——它是唯一既表达空间信息、又**零内在噪声**的 primary 指标。冻结文件当时给的理由（L-001 逐位吻合）成立，但这条理由更强。
2. **任何以 `variogram` 为判据的路线，其阈值必须显著高于 4.2%**（`mmd_u` 则需高于 9%）。**不得**对这两个指标套用 5%。

这是 §4 直接导出的、**现有 9 条候选无一瞄准**的方向：

- **GJC-A（保持）**：以现役 selection 为基座，施加**不破坏基因间联合结构**的改动（例如整体搬运整细胞、组成重采样改为分层整块抽样、或按基因对的自洽约束筛选子集），目标是**在不损失 de/d2/occupancy 既有增益的前提下把 `variogram` 拉回基线水平**。
