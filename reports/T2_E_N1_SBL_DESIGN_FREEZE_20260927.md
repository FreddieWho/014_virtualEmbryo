## 1. 机制（冻结，不得在跑后回改）

对每个源阶段 s ∈ {E6.75, E7.25, E8.0}（按 τ = 0, 1/3, 1）：

1. **几何基底场**（只依赖坐标，不依赖任何表达）：取 K 个 3D 几何派生标量场并各用固定带宽扩散核平滑一次。建议 K = 8，对应：到自身点集凸包的距离（深度坐标）、局部密度（k 半径内点数）、点云 PCA 前 3 主轴、图扩散嵌入前 2–3 分量。**硬性纪律**：扩散核只作用在**几何特征**上；**明令禁止**把任何已预测的表达场再做邻域平均。
2. **阶段内自拟合**：对 log 归一化后**按基因 z-score** 的表达，用强 ridge 回归到这 K 个基底场，得 β_s ∈ R^{498×K}。**每个阶段独立拟合，不依赖跨阶段细胞对应。**
3. **阶段间系数插值**：对每个基因的 K 维系数做一次二阶最小二乘（三点），取 τ = 0.5 得 β̂_E7.5。
4. **目标几何求值**：在 E7.5 的目标点云上计算同一套基底场 b(x)，预测 X̂_i = g(Σ_k β̂_gk b_k(x_i))，其中 g 为 softplus（保证非负）。
5. **全局水平独立通道**：每基因的**阶段均值**单独走「阶段间均值插值」这一条**不含位置**的通道，与局部对比度项**显式解耦**（不写成同一回归里含截距的均值项，避免两者互相污染）。
6. **逐基因门控（预声明，非事后）**：仅对「跨阶段图案稳定」的基因使用 SBL 场贡献，其余基因退回全局均值插值。稳定性判据跑前定死为：|β_E7.25| 与 |β_E8.0| 的余弦相似度 ≥ 0.5（逐基因，在 K 维系数向量上）。**该阈值在首次完整运行前冻结，不得按结果调整。**

**与已关闭 5 轴的距离**（M0 §7）：不做行-点最优传输；不用位移场；不做邻域平滑预测场；不调任何位移量；不做条件流匹配/VAE+SDE/扩散/moscot/生长-死亡动力学；不用按细胞类型的表达均值位移（全局水平只走每基因均值插值）。

## 4. 预声明评价与判定

1. **必须严格优于 do-nothing 基线**（`neighborhood_mmd` 更低）才谈晋级。
2. **必须同时不劣于迭代父版本 v0010**；父版本已在服务器拿到 62.29，本地代理不构成晋级证据，仅作筛选。
3. **分布侧会签的例外（预声明）**：验证 V1（`D-20260927-T2VALIDATE-001`）已发现 `mmd_u` 在 B4-T2-R2 族与服务器反向，且该族本地门双向错过。因此**本路线的分布侧会签不得单独使用 `mmd_u` 做否决**；须 `neighborhood_mmd` 与 `mmd_u` 同向才生效。`mmd_u` 另有 9.0% 种子噪声带，本身也不支持 5% 量级判据。
4. **不得对 `variogram` 套用 5%**：该指标 4.18% 种子噪声，且已被证实是基因间协方差而非本路线的被预测量。

## 5. 预期失败签名（跑前写死，用于识别「为什么失败」而非「失败就放弃」）

| 签名 | 含义 | 正确反应 |
|---|---|---|
| 过平滑塌缩：K 偏小或 ridge 过强 → `d2_shape` 塌向 do-nothing、Moran 全局 I 趋近 0 | 基底不足以表达图案 | 按基因门控收紧（**不是**继续调 ridge） |
| 图案复制：场贡献与 E7.25 的 β 近乎同向，真实相关 ≤ 0 | 该基因图案本身不跨阶段可迁移 | 收紧稳定性门；**不得**放宽到 0 |
| 系数趋零：部分基因 β̂ 趋 0、场贡献消失 | E6.75→E7.25 与 E7.25→E8.0 方向相反 | 事后按 \|β̂\| 排序识别并记录，不重跑挑基因 |
| de_score 掉而 d2_shape 不涨 | 局部对比度对了、全局水平错了 | 拆开两条通道定位，**不得**混合权重后重跑 |

**否定判据**（承自 HX-KILLTEST 先例）：若 L1 与 L2 的 `neighborhood_mmd` 均不优于 do-nothing 基线，本路线**立即关闭**，不扩参数、不改 K、不调 ridge。

## 6. 成本

ridge 为 K ≪ n 的一次 Cholesky 级最小二乘；基底场扩散在 3D kNN 图上做一次。**CPU 数分钟**，5000 细胞 × 498 基因 × K=8/12 均可多次完整跑。无 GPU、无外部数据下载、无新许可。
