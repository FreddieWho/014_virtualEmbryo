# T2 几何新机制冻结：RMS 锁定的各向异性插值

## 为什么是这一刀

用户授权的是几何新机制，不是行集合，也不是封存。三个已关闭轴明确排除：

- 整体坐标缩放（含 ×0.9）。`d2_shape` 和 `occupancy_dice` 都先除以 RMS，各向同性缩放在定义上动不了它们。v0029 只动了 scale 技能，而且变差。
- 加性空间对比度。那是改表达。L-008 已关闭。
- FGW / 把同一配对目标解得更低。落点换了，榜不动。

心脏插值现役 v0019 = 62.36。八项里 scale 97.9、d2 65.4，occupancy 47.8 是高分榜上最大的单孔，而且和父版本 v0013 钉在同一几何三元组。表达配方没有动过这三项。所以第一刀只改坐标形状，表达、行序、细胞数、整体 RMS 都锁定。

心脏外推不在这一刀里。E10.5 两侧没有训练括号，外推形状是另一条假设。

## 假设

H-GEOM-1：心脏插值的 occupancy 孔是规范坐标系里的占据支撑偏了，不是整体大小偏了。现役点云若是两个括号阶段几何的混合（并集/平均），它会同时不像 E8.25 也不像 E8.75。各向异性谱（三个主轴相对长度）若随阶段变，把现役拉到两阶段谱的日历中点，应同时更靠近两个括号，而不是滑向其中一端。

这条假设只解释椭球各向异性。叶、管、空洞这类高阶支撑不在本刀的机制里。若括号之间谱几乎不变、或占据已经很像，本刀关闭，不改成非线性形变再跑。

## 机制（唯一，无搜索）

只读 `obsm["spatial_3D"]`。不读表达矩阵。不读 E7.5 / E8.5 / E10.5 / E12.5 / E7.75。

1. 去中心。RMS = 到质心距离的均方根。
2. 各向异性谱：总体协方差特征值降序，`a_i = sqrt(λ_i) / RMS`。三个数的平方和为 1，与整体大小无关。
3. 目标谱 = `(1-t) * a_早 + t * a_晚`。不插特征值本身，不搜索 t。
4. 在**现役自己的** PCA 轴上，第 i 轴拉伸 `a_目标_i / a_现役_i`。不把阶段轴旋转到现役轴上。
5. 拉伸后把 RMS 乘回现役原值，质心放回原处。scale 技能因此在构造上不变。

心脏插值：括号 E8.25_late → E8.75，目标 E8.5，`t = 0.5`。现役 `v0019_h_o1_shrinkmerge`。

胚胎插值只做同一代码的复现读，不调参：括号 E7.25 → E8.0，目标 E7.5，`t = (7.5-7.25)/(8.0-7.25) = 1/3`。现役 `v0014_e_o1_shrinkmerge`。两板分开判，不平均。

## 对照（必须先过）

- 拉伸全为 1：与现役坐标在 dice / d2 上一致（同一种子）。
- 各向同性 ×0.9 再锁回 RMS：形状指标必须回到现役。否则实现把已关闭的尺度轴漏进了形状。
- RMS 相对变化 `< 1e-6`。不过就是实现错误，修实现，不改定义。

指标实现：`third_party/veckit/common/shape_metrics.py` 的 `occupancy_dice` 与 `d2_distance`，种子 0，默认参数。

## 判据（写死，看见数字后不得改）

能力门，先于输赢：

- 两括号谱的最大绝对差 `< 0.05`：`INSUFFICIENT_ANISOTROPY`。线性各向异性不是这条轨迹的信号。关闭本族。
- 两括号的 occupancy dice `≥ 0.90`：`SUPPORT_STABLE`。训练阶段之间占据几乎不动，插值它们解释不了 47.8 的孔。关闭本族。

两条都触发就两条都记，结论仍是关闭。

能力门通过之后：

- **CONTINUE**：形变相对两个括号的 dice 都严格高于现役，且相对每个括号的 d2 `≤` 现役的 1.10 倍。
- **STOP**：只靠近一个括号、两个都不靠近、或任一括号上 d2 变差超过 10%。关闭本族。

胚胎单独用同一套句子。心脏 CONTINUE 且胚胎不 CONTINUE，记 `HEART_ONLY_CONTINUE`，不得写成通用几何定律。

## CONTINUE 不是什么

- 不授权本回合建候选。
- 对括号的 dice 不是服务器 occupancy 技能。验证 V1 已表明本地几何指标可以和服务器反向。
- 不得用这次数字去改 t、改插值对象、或升级成非线性形变。那是新冻结。
