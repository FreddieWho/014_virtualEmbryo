## 3. 检索浮现的一个结构性观察（比单条路线更值得押）

**6 条新路线里有 3 条独立收敛到同一个被预测量——经验变差函数 / 空间二阶结构**：

- `E-N2 VGM`：用目标点云的变异图/相关图**形状**做校准
- `H-N1 VMS`：按源阶段残差场功率谱合成纹理，使经验变异函数**匹配**
- `X-N1 vario-continuation`：直接外推变差函数 γ_g(s;t) **本身**

三条来自三个互不相关的 board 与三套不同机制（无标签校准 / FFT 谱合成 / 层级时间外推），却指向同一个对象。这**独立佐证**了架构重置文件 §9 的判断（heart 的 variogram 28 是明确 headroom）——三条路线互为交叉验证，比任何单条的文献支撑都强。

**同时必须记下的风险**：若 variogram 这个被预测量本身是代理假象（而不是真实 headroom），这 3 条会**同时**失败，代价是 3 个 lane 槽位。缓解是它们分布在三个 board、机制各异，失败相关性只是部分而非完全；且每个 board 都另配 1 条**非** variogram 族的迭代路线（E-I1 / H-I1 / X-I1），保证不会出现「某板三条全押同一注」。

## 4. 三条检索者自报的存疑项（必须带入定稿，不可略过）

1. **`variogram 28` 这个 headroom 是 heart 板的**。embryo 板的子分权重与官方 variogram 的精确算法**未知**，这直接决定 `E-N2 VGM` 值不值得做。
2. **官方 variogram 子分的定义无法查证**（heart 板）。`H-N1 / H-N2 / H-I1` 的收益排序**完全取决于**它是「细粒度纹理」型还是「粗尺度一致性」型——这两类需要完全不同的建模方式。
3. **无先例诚实标注**：`X-N1`（跨阶段外推变差函数）与 `X-N2`（占据模型做心脏发育外推）在本方向**查不到任何直接先例**。组件有先例、组合无先例。这是激进程度的来源，也是必须先跑小探针的原因。
4. `H-N1 / H-N2` 亦被标注「组合无现成先例」。
5. **全部 66 个 URL 仅核实到题名/期刊/DOI 层，未读全文**。承重引用（Perler 的基底构造、MacKenzie 递推式的可识别性条件、Sagittarius 的正则化结论）**必须由 coordinator 用 `web_read` 核验原文后才可进入设计冻结**。
